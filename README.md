# 图像分割工具 - C++ Qt GUI 版本

## 功能概述
本项目是一个基于 C++ 和 Qt5 的图形化界面应用，支持：
任务1:
- 上传本地图像文件
- 自定义 K 值（种子点数量）
- 实时查看原始图像和分割结果
- 保存分割结果

任务2：
- 对分水岭区域建立邻接表
- 使用四原色法对区域重新着色
- 支持 BFS 顺序梳理 + 栈回溯着色
- 支持基准测试（失败率与耗时统计）

采样策略：
- 主采样阶段：采用多相位六角晶格初始化，以 D = sqrt(M*N/K) 为约束基准，在多组晶格偏移中选择可行点最多的一组。
- 距离约束：候选点只有在与已有种子点距离严格大于 D 时才会被接受，确保点间不会过近。
- 加速机制：使用空间哈希（邻域桶）做局部近邻检查，仅比较候选点附近少量种子，避免全量 O(K^2) 距离暴力比较。
- 均匀增强：当候选集数量超过 K 时，再用最远点采样（FPS）从候选集中选出 K 个点，使分布更稳定、更接近六边形均匀态。
- 补点策略：若六角晶格在整数像素网格上仍不足 K，则在不放宽阈值的前提下进行严格随机补点。
- 唯一性与可行性：输出点均为互异坐标；若在严格距离约束下客观不可达 K，则返回当前可行的最大合法点集。

任务2重着色策略：
- 邻接建图：将分水岭输出中的每个正标签区域视作图节点，基于像素邻接与边界像素恢复区域邻接关系，构造无向邻接表。
- 初始顺序：先通过 BFS（队列）生成区域访问顺序，并优先从高连接度区域启动，以更早处理约束更强的节点。
- 选点策略：着色过程中动态选择“当前约束最多”的未着色节点（饱和度优先，其次度数优先，再参考 BFS 顺序）。
- 选色策略：优先尝试在局部邻域中使用最少、且全局使用较少的颜色，降低后续冲突概率。
- 栈式回溯：采用显式栈替代递归。每层记录当前节点、已尝试颜色、以及对邻居禁用掩码的增量改动，失败时可精确回滚。
- 前向剪枝：每次试色后立即检查是否出现“无可用颜色”的未着色节点，若出现则立即回退，减少无效深搜。
- 运行保护：设置最大回溯次数与最大耗时阈值，避免极端输入导致长时间阻塞。

## 系统需求
- macOS 10.12+ 或 Linux
- C++ 17 标准编译器
- CMake 3.10+
- OpenCV 4.5+
- Qt5 5.15+

## 安装步骤

### 1. 安装依赖（macOS）

```bash
# 使用 Homebrew 安装依赖
brew install opencv qt5 cmake
```

### 2. 编译项目

```bash
# 进入项目文件夹
cd dataStructure

# 创建 build 目录
mkdir -p build

# 配置并编译
cmake -B build
cd build
make
```

### 3. 运行应用

```bash
# 运行 GUI 版本
./task_gui

# 运行命令行版本
./task

# 运行任务2命令行版本（四原色重着色）
./task2 ../assets/fruits.jpg ../outputs/task2_colored.png 120

# 运行任务2基准测试
./task2 --benchmark ../assets/fruits.jpg 20
```

## 使用说明

### 启动应用
运行 `./task_gui` 后，会弹出 GUI 窗口。

### 1.选择图像
- 点击 **"浏览文件"** 按钮
- 选择要处理的图像文件（支持 JPG、PNG、BMP、TIFF 等）
- 选定后，原始图像会显示在 **"原始图像"** 标签页中

### 2.设置参数
- **K 值**：设置种子点数量
- 使用微调框选择合适的 K 值

### 3.执行分割
- 点击 **"开始分割"** 按钮
- 应用执行以下步骤：
  1. 生成均匀分布的种子点
  2. 执行分水岭分割算法
  3. 生成并显示结果
- 进度会在状态栏实时显示

### 步骤 4：查看结果
- 状态栏显示处理时间和种子点数量
- 红色圆点为原始种子点位置

### 步骤 5：保存结果
- 点击 **"保存结果"** 按钮
- 选择保存位置和格式（PNG 或 JPG）
- 分割结果保存为指定文件
